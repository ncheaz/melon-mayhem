Architecture — simulation untouched

  • js/render3d.js (new): Three.js r149 (vendored, no build step). The sim in game.js still runs in board space (u, row, h) with identical physics; the 3D layer mirrors state into a perspective scene every frame.
  • World mapping: x=(u-4.5)*10wu, z=(row-1.5)*9.55wu, 1 h-unit = 4.32wu — derived from the old pixel metrics, so every gameplay value survives verbatim.
  • Board re-derivation: with a yaw-free camera, lanes project to horizontal lines and columns stay linear per row — Board.laneY/rowScale are recomputed from the live camera at boot, so ALL 2D overlay math (popups, aim arc, force bar, FX anchors) sits exactly on the 3D meshes with zero changes to the drawing code.
  • Pointer aim: mouse ray unprojects onto the ground plane through the real camera, then re-encodes as the lane's screen x — apex aim feels identical to 2D.
  • Fallback: ?flat=1 renders the legacy 2D pipeline entirely.

What is real 3D now

  • Camera: perspective fov 44deg, pitch ~44deg, solved numerically so the near lane keeps its tuned scale; BTD6-style "map fills the frame" with a hedge treeline crowning the top edge.
  • Characters: low-poly toon-shaded meshes — zombie (rounded cranium, jaw, outstretched arms, bucket helmet, plank shield, hit-flash emissive, per-state pose anim), melon-pult (urn body, face to camera, chunky throwing arm + scoop + held melon), tombstones, dressing (bushes/flowers/rocks), cottage, graveyard gate, windmill, clouds.
  • Projectiles: real meshes on the unchanged ballistic arc + 16-bead world-space trail + flight blob shadow; launch bridge is a true 3D quadratic bezier from the arm tip.
  • Grounding: PCF-soft sun shadows plus BTD6-style blob shadows under every actor (shrink with hop/flight height).
  • Lighting: toon gradient ramp (4-step), warm key + sky/ground hemi, tuned over 5 rounds so shadows read at gameplay scale.
